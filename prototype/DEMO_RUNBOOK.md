# Demo Day 操作手冊

攤位上照這份做就好。劇本內容看 `02_規格定義/04_Demo規劃.md`，這裡只寫「怎麼開、怎麼重來、出事怎麼辦」。

## 開場前（提早 30 分鐘）

1. 筆電接電源、接外接螢幕，連上會場網路（備著手機熱點）。
2. 開終端機：

   ```bash
   cd prototype
   scripts/demo.sh          # 只用筆電
   scripts/demo.sh --lan    # 要讓手機開技術員頁面（手機要跟筆電在同一個網路）
   ```

   腳本會檢查 `.env` 金鑰、YOLO 權重、影片，清掉上一場的資料，啟動前後端，最後印出系統狀態和網址。
   看到「Jev：開　LLM：開」才算正常。哪一項顯示「關」，先看下面的備案。
3. 外接螢幕開 `/`（戰情儀表板），筆電開 `/control`（控制台）。手機開 `/m/工單號`，等卡料工單建立後再開。
4. 先空跑一次場景 2（卡料），確認 Jev 有框、LLM 說明有出來、Agent 回得了話。跑完到控制台按「重置」。
5. 控制台「升級逾時」改成 30 秒，展示升級時才不用等 5 分鐘。

右上角的「身分」下拉選單用來切換技術員／班長／主管。評審想自己點的話，切成「評審（唯讀）」，畫面看得到但按不了。

## 標準流程（約 5 分鐘）

1. 儀表板總覽：三條產線、攝影機牆、右邊即時告警。
2. 場景 1 PPE：控制台按「場景 1」，YOLO 框出沒戴安全帽的人，工安單直接派給班長，不叫 LLM。
3. 場景 2 卡料：按「場景 2」，等 Jev 框出卡料位置、根因前三名出現。到任務看板點進工單。
4. 技術員「接單」→「申請作業許可」→ 切成班長按「核准作業許可」→ 切回技術員，LOTO 一步一步勾。
5. 勾完自動進入維修，跟 Agent 對話。最後問「卡住的料片可以直接伸手拿嗎？」，Jev 會把危險步驟標紅、要求主管確認。切成主管按「主管確認」。
6. 切回技術員勾完工 Checklist，結案回報按「帶入範例」再提交，J5 通過後切成主管按「核准入庫」。
7. 有時間的話再按一次場景 2，Agent 會引用剛才入庫的案例。
8. 最後到「效益」頁講反應時間、MTTR、AI 成本。

## 換評審之間

- 控制台按「重置」，確認對話框按確定。工單、事件會清空，攝影機回到正常畫面。不用重開程式。
- 身分切回技術員。
- 如果畫面怪怪的（例如右上角一直顯示「連線中」），瀏覽器重新整理一次就好。
- 真的卡住：終端機 Ctrl-C，再跑一次 `scripts/demo.sh`，大約 30 秒回來。

## 出狀況時

| 狀況 | 怎麼做 | 跟評審怎麼說 |
|---|---|---|
| Jev 很慢或一直逾時 | 控制台「Jev 直覺層」切成關閉，再跑一次劇本。規則照樣建單派工，工單上會寫「AI 判斷暫不可用」 | 這就是我們的退路設計：AI 掛了，告警和派工不會停 |
| LLM 說明沒出來 | 不用處理，派工通知本來就先送出，說明是之後補的。可以直接帶評審看 SOP 區塊 | 說明是加分，不在關鍵路徑上 |
| 會場網路斷了 | 先切手機熱點；熱點也不行就播備份影片 `prototype/assets/demo/backup_demo.mp4`（沒有 mp4 就開 `.webm`，用 Chrome 拖進去就能播） | 現場網路不穩，先看完整錄影，網路回來再現場操作 |
| 筆電當機或沒反應 | 換第二台筆電。第二台事前要先跑過一次 `scripts/demo.sh`，`.env`、`models/ppe.pt`、影片都要先複製好 | — |
| 手機開不了 `/m/…` | 確認是用 `--lan` 啟動、手機和筆電在同一個網路。來不及就直接在筆電點工單頁右上角「技術員手機版」 | — |
| 腳本說埠被占用 | 上一場沒關乾淨。`lsof -iTCP:8000` 找到 PID 後 kill，再重跑 | — |

## 備份影片

`prototype/assets/demo/backup_demo.webm`（和同名 `.mp4`）是用 Playwright 照上面流程錄的，不進 git。要重錄：

```bash
cd prototype/frontend
# 先用 demo.sh 或手動啟動前後端
E2E_BASE_URL=http://localhost:3000 node e2e/record-demo.mjs
```

## 收攤

終端機按 Ctrl-C，前後端會一起關掉。
