## E1 根因判斷（Jev J1–J3，題目 event-2026-10-20.3）
方法：依正式流程組 state——facts 由 log_signals／trigger／context 程式算出、時間線同一批 Log、相似案例用正式 `KnowledgeBase.similar_cases`（k=5、line＋machine_type）從非 heldout 200 筆取、候選用 `failure_modes_for`，呼叫正式 `judge.event`、`gate.decide`；不使用任何事後欄位。

| 指標 | 結果 |
|---|---|
| **根因 Top-1** | **86.5%（32/37）[72.0–94.1%]**（排除誤報 2、新模式 1） |
| Top-3 | 100%（37/37）；隨機基準 Top-1 11.7%／Top-3 35% |
| 依產線 Top-1 | 沖壓 78.9%（15/19）、銲接 100%（9/9）、組裝 88.9%（8/9） |
| 依類型 Top-1 | 典型 88.9%（24/27）、第一判斷錯誤 75%（6/8）、升級 2/2 |
| 類別 | 67.5%（27/40）[52.0–79.9%]；主錯 equipment↔quality |
| 嚴重度 | 原始 90.0%（36/40）；gate 後 92.5%；S3 1/1 |
| 誤報 | 召回 **0/2**（p 0.31、0.38）；AUROC 保留 1.00（2 正例）、保留＋合成 0.946（12 正例）；正式門檻 0.9 下 0 筆真事件被壓掉 |
| 目錄外新模式 | 1/1 被塞進既有模式（題目無 new 選項） |
| 延遲 | P50 0.46 s、P95 0.66 s（n=40） |
| 成本 | US$0.000139／次 |
| 分流（conf≥0.6） | jev_top3 39、llm_deep 1（97.5%） |

穩定度：40/40 三次 Top-1 與類別相同；機率 SD 平均 0.006。選項順序打亂：40/40 Top-1 不變，準確率變化 0.0 pp；Top-1 落在第一選項僅 12.5%。檢索上限：top-5 相似案例含正確根因 67.6%，相似案例多數決 54.1%。

壓力測試：塞無關訊號 94.6%（35/37）（與乾淨版相同，屬小樣本波動）；合成複合原因 80.0%（16/20）[58.4–91.9%]（Top-1 為主或次因 95%、兩因皆入 Top-3 75%）；合成集內複合 **44.4%（4/9）**、升級 **40%（2/5）**＝弱項。

成本拆解（10 筆）：4 題＋相似案例 US$0.000138（3,292 tok）；只問根因 0.000120；只問類別 0.000077；4 題不帶案例 0.000095。每天 2,000 事件約 US$0.28。
